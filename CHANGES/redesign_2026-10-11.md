# Redesign pass — 2026-10-11 (overnight)

Applied the "DailyPlanner Redesign" design canvas to the app, plus the bugs
and security gaps found along the way. Every commit went to `main` after the
full test suite passed (592 → 619 tests, 0 failures). The branch
`redesign/plus-jakarta` points at the same commits as a backup.

## 1. Run this SQL in Supabase

All three files are safe to re-run. The app works before you run them — new
columns are stripped and retried, history writes are skipped — you just
don't get the new data until they're in.

| Order | File | What it adds |
|---|---|---|
| 1 | `MIGRATION_KR_CHECKINS.sql` | `key_results.last_checked_at` (backfilled from `created_at`) and the `kr_checkins` history table, for the weekly check-in |
| 2 | `MIGRATION_PROJECT_COLOR.sql` | `projects.color` with a hex-only CHECK, for the colour picked when creating a project |
| 3 | `MIGRATION_TASK_COMPLETED_AT.sql` | `project_tasks.completed_at`, kept by a trigger whenever a task becomes done / un-done, for the sprint burndown |

## 2. What changed

**Look (all pages, through the design tokens)**
- Ink & Lime palette: near-black primary with a white label, lime in dark
  mode with an ink label; indigo for links, the active nav and focus.
  Neutral stone ground. All contrast pairs still pass
  `tests/test_palette_contrast.py` in both themes.
- Plus Jakarta Sans everywhere (also for numbers, with tabular figures).
- Softer radii, bold tight headings, PWA theme colours.
- ~30 hard-coded old blues became tokens. 123 white-on-primary labels now
  use `--color-on-primary`, so nothing is white-on-lime in dark mode.
- Priorities quote banner is a flat ink card. The 404 and 500 pages are
  redesigned (with dark mode and useful actions).

**New**
- `/goals/check-in` — weekly check-in for hand-kept key results. A
  "Weekly check-in" button on Goals, and each key result shows "updated N
  days ago", flagged after a week.
- Project colour on the new-project form, the project cards and the
  Roadmap.
- Menu links to Day timeline, Settings and Pending sync, which had no way
  in.

**Fixed**
- Dark mode: Priorities quadrant titles and the Inbox heading were
  near-black on near-black (this predates the redesign).
- Checklist history streak read 0 all day until the last tick. An
  unfinished today no longer counts as a miss.
- Health score gave 10 free points (a constant weight score).
- The top bar's avatar sat 14px off-screen. The Quick Bucket text box
  overflowed on phones. A grey band showed down the left edge on phones
  (the closed menu's shadow).
- A raw "+" and a row of plain links appeared under pages that load
  `pt-shared.js` without its CSS.
- `/untimed/schedule` upsert used the wrong conflict key, so it always
  failed.
- Ticking a matrix task never synced its linked project task (a
  `get(single=True)` TypeError).

**Security**
- 27 write endpoints acted on a row id without checking the owner. Any
  signed-in user could edit or delete another user's project tasks,
  matrix tasks, subtasks, habit order or Roadmap dates. All are now
  scoped to the caller (`tests/test_ownership.py`). The vault, money,
  chat and family features were already correct.

## 3. Second pass (same night)

- **Read-side security audit**: all 495 reachable reads checked. Fixed:
  - reading another user's task text via send-to-matrix;
  - other users' key-result titles on the day board;
  - tasks linked to someone else's project, goal, KR, initiative, epic or
    sprint, now refused on create and update;
  - family-task titles in search for non-family accounts;
  - the people picker listing everyone;
  - admin access falling back to the whole family (set `ADMIN_EMAILS`);
  - chat attachments without a room;
  - cross-user duplicate checks;
  - a constant-time cron-secret check.
- **Dead code removed**: `load_todo`, `save_todo`, `get_goal_for_date`,
  `services/reminder_service.py`.
- **Share to DailyPlanner** confirm page, saving to Inbox, TravelReads or
  References.
- **Sprint burndown** over the sprint's own dates.
- **Reminders prompt**: says what is sent, and "Not now" is remembered for
  14 days.
- **Today**: first-run steps for a new account; loading skeleton on the
  home list.
- **Speed**: the font is now self-hosted. The first commit had made every
  page wait on Google Fonts, so first paint went from ~0.93 s to ~1.35 s
  on a phone connection; it is back to ~0.9 s.

## 4. Not done (needs a decision or more time)

- Most mockup screens beyond the tokens are not built page by page. Pages
  pick up the palette, type and radii, but their layouts are unchanged.
  The canvas shows the target for each.
- `routes/events.py`: the iCal feed token is predictable if neither
  `ICAL_FEED_SECRET` nor `FLASK_SECRET_KEY` is set. Make sure one is set
  in production.
- Pre-existing, not changed:
  - the service worker re-checks every JS/CSS file with the server on
    each page load (a 304 per file);
  - feather-icons loads render-blocking from unpkg on many pages.
  Both cost some speed and are worth a separate pass.
